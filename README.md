# iRestore Hub - Tech Repair Landing Page

## 📍 Overview
This project is a minimal, responsive landing page for a tech repair service called "iRestore Hub." It was built to demonstrate the rapid UI development capabilities of Tailwind CSS integrated into a modern React environment.

This codebase serves as the "Minimal Working Example" for a capstone project exploring new technologies using Generative AI.

## 🛠️ Technology Stack
* **Frontend Framework:** React.js
* **Build Tool:** Vite (for fast scaffolding and Hot Module Replacement)
* **Styling:** Tailwind CSS (Utility-first CSS framework)
* **Environment:** Node.js
